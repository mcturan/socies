1. Gerçekleştirilen Mimari Değişiklikler

ÖzellikTasarım & ÇözümKullanıcı Deneyimi
Ekran Solda, 4 Buton Sağda Dikey 0.96" OLED sol tarafa yerleştirildi. 4 adet taktil buton sağ tarafta yukarıdan aşağıya dizildi. Sağ el başparmağının 4 tuşa dikey eksende tek hamlede rahatça ulaştığı ergonomik tutuş.
Titreşim Motoru + Buzzer Kutu içerisine NPN transistör/MOSFET sürücülü mini ERM titreşim motoru eklendi. Cepte taşınırken gelen çağrılarda, dürtmelerde (poke) ve kritik uyarılarda dokunsal titreşim hissi.
Kısa & Uzun Basma Fonksiyonları 600ms eşikli uzun basma motoru yazıldı:
- Tuş 1: Kısa: Yukarı | Uzun: Ses Aç/Kapat (Mute)
- Tuş 2: Kısa: Seç | Uzun: BLE Eşleşme Modu
- Tuş 3: Kısa: Aşağı | Uzun: Titreşim Aç/Kapat
- Tuş 4: Kısa: İptal | Uzun: Tüm İhtiyaçlar HUD Ekranı 		Ekstra tuş kalabalığı olmadan tüm cihaz ayarları ve durum ekranı 4 tuşla yönetilir. Üst sarı barda simgeler anlık değişir.

Çağrı Cihazı (Pager) Mesajlaşması (Madde 9) Telefondan yazılan 32 karaktere kadar kısa mesaj BLE ile cihaza iletilir. Cihaz 90'ların çağrı cihazı gibi titrer ve öter; üst barda zarf [✉] simgesi belirir ve mesaj ekranda kayan yazı olarak akar.
İlk Hayvan: SOSİS (Madde 10) Tombiş, kıvrılan, sevimli mimikleri olan Sosis karakteri modellendi. Bebekken minik sosis, yetişkinken hardal/ketçap şapkalı sevimli gurme sosis, 90. günde "Pastırma/Folyo Kozası", sonra Siber Mega Sosis!

💻 ESP32 C++ Kodu (Uzun Basma Mantığı & Çağrı Cihazı Servisi)

// SOCIES PAGER & SANAL BEBEK FIRMWARE
// 4 Dikey Tuş için Kısa / Uzun Basma Algoritması ve Pager BLE GATT Karakteristiği

#define PIN_BTN_UP     0
#define PIN_BTN_ACTION 1
#define PIN_BTN_DOWN   2
#define PIN_BTN_BACK   3
#define PIN_BUZZER     4
#define PIN_VIBRO      6

#define LONG_PRESS_MS  600 // 600ms üzeri basılı tutma uzun basmadır

// Titreşim Motorunu Tetikleme
void triggerVibration(int durationMs) {
  digitalWrite(PIN_VIBRO, HIGH);
  delay(durationMs);
  digitalWrite(PIN_VIBRO, LOW);
}

// Pager Çağrı Cihazı BLE Karakteristiği (Mobil Uygulamadan Metin Gelince)
class PagerCallback: public NimBLECharacteristicCallbacks {
  void onWrite(NimBLECharacteristic* pChar) {
    std::string msg = pChar->getValue();
    if (msg.length() > 0) {
      // Nostaljik Çağrı Cihazı Titreşim ve Ses Deseni: Bip-Bip-Bip + Titreşim
      for(int i=0; i<3; i++) {
        digitalWrite(PIN_VIBRO, HIGH);
        tone(PIN_BUZZER, 1200, 80);
        delay(100);
        digitalWrite(PIN_VIBRO, LOW);
        delay(80);
      }
    }
  }
};
