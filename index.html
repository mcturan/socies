📐 Socies Donanım Mimarisi & Devre Şeması

Socies sanal bebek donanımı, ultra düşük güç tüketimi, kompaktlık ve cepte taşınabilirlik amacıyla ESP32-C3 SuperMini veya ESP32-Pico-D4 üzerine tasarlanmıştır.

1. Bileşen Listesi (BOM - Bill of Materials)

Bileşen Model / Tip Görevi & Özellikleri
Mikrodenetleyici ESP32-C3 SuperMini (veya WROOM-32) 160MHz RISC-V, Dahili Wi-Fi & BLE 5.0, 4MB Flash, Deep Sleep (5µA)
Ekran 0.96" 128x64 4-Pin OLED (SSD1315 / SSD1306) I2C Arayüzü, Sarı (Üst 16px) - Mavi (Alt 48px) çift renk alanı
Güç Kaynağı 3.7V Lityum Polimer (500mAh - 1000mAh) Cihaz boyutuna göre yassı Li-Po pil (örneğin 503035 veya 18650)
Şarj Modülü TP4056 Type-C Korumalı Şarj Kartı DW01A + 8205A batarya korumalı, 5V Type-C giriş, 1A ayarlanabilir şarj
Düğmeler 4x SMD/Taktil Buton (6x6x5mm) Sol, Sağ, Seç, İptal + Harici Donanım Reset & Sürgülü Açma/Kapama
Ses (Audio) Pasif Piezo Buzzer (9mm SMD/Through-hole) 8-bit chiptune melodiler, acil ihtiyaç alarmları, PWM ton üretimi
Batarya Monitörü 2x 100kΩ Direnç (Gerilim Bölücü) Li-Po pil voltajını ADC üzerinden okuyup % pil seviyesi hesaplar

2. Pin Bağlantı Tablosu (Pinout)

ESP32-C3 Pini Bağlanan Bileşen Açıklama / Konfigürasyon
GPIO 8 (SDA) OLED SDA I2C Veri Hattı (Dahili / Harici 4.7kΩ pull-up)
GPIO 9 (SCL) OLED SCL I2C Saat Hattı
GPIO 0 Buton 1 (SOL / YUKARI) INPUT_PULLUP (Butona basılınca GND'ye çeker)
GPIO 1 Buton 2 (SEÇ / AKSİYON) INPUT_PULLUP (Wake-up pin olarak da kullanılır)
GPIO 2 Buton 3 (SAĞ / AŞAĞI) INPUT_PULLUP
GPIO 3 Buton 4 (İPTAL / GERİ) INPUT_PULLUP
GPIO 4 Pasif Buzzer (+) LEDC Donanımsal PWM çıkışı (8-bit tonlar)
GPIO 5 (ADC1) Batarya Gerilim Bölücü Pil (+) kutbundan gelen 100k / 100k bölücü orta noktası (0-2.1V)
3V3 & GND Tüm Modüller ESP32 regülatör çıkışı ve ortak şasi hattı
⚡ Pil Ömrü Optimizasyonu: Cihaz kullanılmadığında 60 saniye sonra OLED ekranı kapatarak ESP32 Deep Sleep moduna geçer. GPIO1 (Seç butonu) harici uyandırma (EXT0 Wakeup) olarak ayarlanır. Bu sayede 500mAh pil ile 20 güne varan bekleme süresi elde edilir.

💻 ESP32 C++ / Arduino Kaynak Kodu (Firmware)

Aşağıdaki kod, U8g2 OLED grafik kütüphanesi ve NimBLE-Arduino Bluetooth kütüphanesi kullanarak Socies mantığını, Sims ihtiyaç döngüsünü ve BLE telemetrisini çalıştıran tam teşekküllü üretim kodudur.

/**
 * SOCIES SANAL BEBEK - ESP32 FIRMWARE
 * Donanım: ESP32-C3 SuperMini, 0.96" SSD1315/SSD1306 OLED (I2C), 4 Buton, Buzzer
 * Kütüphaneler: U8g2lib, NimBLEDevice, Preferences (NVS Flash Kayıt)
 */

#include <Arduino.h>
#include <U8g2lib.h>
#include <Wire.h>
#include <NimBLEDevice.h>
#include <Preferences.h>

// PIN TANIMLARI
#define PIN_OLED_SDA  8
#define PIN_OLED_SCL  9
#define PIN_BTN_LEFT  0
#define PIN_BTN_OK    1
#define PIN_BTN_RIGHT 2
#define PIN_BTN_BACK  3
#define PIN_BUZZER    4
#define PIN_BATTERY   5

// OLED EKRAN BAŞLATMA (SSD1306 / SSD1315 128x64 I2C)
U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, U8X8_PIN_NONE, PIN_OLED_SCL, PIN_OLED_SDA);

// BLE GATT UUID TANIMLARI
#define SERVICE_UUID        "180F" // Socies Service
#define CHAR_TELEMETRY_UUID "2A19" // Needs & Stats Notify
#define CHAR_ACTION_UUID    "2A20" // App Commands Write

NimBLEServer* pServer = nullptr;
NimBLECharacteristic* pTelemetryChar = nullptr;
Preferences preferences;

// SİMS İHTİYAÇLARI YAPISI
struct PetState {
  uint8_t petType;      // 0:Kedi, 1:Kopek, 2:Kus, 3:Balik, 4:Sosis, 5:Pacman, 6:Yengec
  uint8_t stage;        // 0:Yumurta, 1:Bebek, 2:Cocuk, 3:Yetiskin, 4:Koza, 5:Mega
  uint16_t ageDays;
  uint32_t totalScore;
  
  // 7 Sims Ihtiyaci (0 - 100 arasi)
  int hunger;
  int fun;
  int love;
  int sleep;
  int toilet;
  int clean;
  int social;
  
  uint8_t zeroNeedsDays; // 5 gun kurali sayaci
  bool isSleeping;
};

PetState pet = {0, 1, 1, 100, 85, 70, 90, 65, 80, 75, 60, 0, false};

// 8-BIT SES MOTORU
void playBeep(int freq, int durationMs) {
  tone(PIN_BUZZER, freq, durationMs);
}

void playJingleHappy() {
  playBeep(523, 100); delay(120);
  playBeep(659, 100); delay(120);
  playBeep(784, 150);
}

void playAlarmWarning() {
  for(int i = 0; i < 3; i++) {
    playBeep(880, 80); delay(100);
    playBeep(440, 80); delay(100);
  }
}

// SIMS IHTIYAC TUKETIM FONKSIYONU (Periyodik Calisir)
void decayNeeds() {
  if(pet.stage == 0 || pet.stage == 4) return; // Yumurta veya kozada azalmaz

  // Hayvan cinsine gore ozel katsayilar
  int hungerRate = (pet.petType == 2) ? 3 : 2; // Kus hizli acikir
  int cleanRate  = (pet.petType == 3) ? 3 : 1; // Balik temiz su ister
  
  pet.hunger = max(0, pet.hunger - hungerRate);
  pet.fun    = max(0, pet.fun - 2);
  pet.love   = max(0, pet.love - 1);
  pet.toilet = max(0, pet.toilet - 2);
  pet.clean  = max(0, pet.clean - cleanRate);
  pet.social = max(0, pet.social - 1);
  if(!pet.isSleeping) pet.sleep = max(0, pet.sleep - 1);

  // %50 ALTI UYARI KONTROLU
  bool hasWarning = (pet.hunger < 50 || pet.fun < 50 || pet.love < 50 || 
                     pet.toilet < 50 || pet.clean < 50 || pet.social < 50);
  if(hasWarning) {
    playAlarmWarning();
  }

  // 5 GUN TUM IHTIYACLAR SIFIR KURALI
  if(pet.hunger == 0 && pet.fun == 0 && pet.love == 0 && 
     pet.toilet == 0 && pet.clean == 0 && pet.social == 0) {
    pet.zeroNeedsDays++;
    if(pet.zeroNeedsDays >= 5) {
      if(pet.stage > 1) {
        pet.stage--; // Level duser
      } else {
        pet.stage = 0; // Yumurtaya doner!
      }
      pet.zeroNeedsDays = 0;
    }
  } else {
    pet.zeroNeedsDays = 0;
  }
}

// OLED EKRAN CIZIM FONKSIYONU (128x64)
void renderScreen() {
  u8g2.clearBuffer();

  // === UST 16 PIKSEL SARI BOLGE (STATUS BAR) ===
  u8g2.setFont(u8g2_font_profont10_mr);
  u8g2.setCursor(2, 10);
  u8g2.print("SOCIES");
  
  u8g2.setCursor(54, 10);
  u8g2.printf("G:%d", pet.ageDays);

  u8g2.setCursor(92, 10);
  u8g2.print("BAT:85%");

  u8g2.drawHLine(0, 14, 128); // Sari-Mavi ayrim cizgisi

  // === ALT 48 PIKSEL MAVI BOLGE (SPRITE & OYUN) ===
  if(pet.stage == 0) {
    // Yumurta
    u8g2.drawDisc(64, 42, 12);
    u8g2.setCursor(44, 60);
    u8g2.print("Catlat!");
  } else if(pet.stage == 4) {
    // Koza
    u8g2.drawFrame(52, 24, 24, 34);
    u8g2.setCursor(42, 62);
    u8g2.print("KOZA EVRESI");
  } else {
    // Hayvan Sprite Cizimi (Ornek Kedi)
    u8g2.drawDisc(64, 40, 10); // Kafa
    u8g2.drawTriangle(56, 33, 59, 25, 63, 31); // Sol Kulak
    u8g2.drawTriangle(65, 31, 69, 25, 72, 33); // Sag Kulak
    
    u8g2.setCursor(35, 60);
    u8g2.printf("Ac:%d%% Sev:%d%%", pet.hunger, pet.love);
  }

  u8g2.sendBuffer();
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_BTN_LEFT, INPUT_PULLUP);
  pinMode(PIN_BTN_OK, INPUT_PULLUP);
  pinMode(PIN_BTN_RIGHT, INPUT_PULLUP);
  pinMode(PIN_BTN_BACK, INPUT_PULLUP);
  pinMode(PIN_BUZZER, OUTPUT);

  u8g2.begin();
  
  // NimBLE BLE Server Baslatma
  NimBLEDevice::init("Socies_ESP32_C3");
  pServer = NimBLEDevice::createServer();
  NimBLEService* pService = pServer->createService(SERVICE_UUID);
  pTelemetryChar = pService->createCharacteristic(
    CHAR_TELEMETRY_UUID,
    NIMBLE_PROPERTY::READ | NIMBLE_PROPERTY::NOTIFY
  );
  pService->start();
  NimBLEAdvertising* pAdvertising = NimBLEDevice::getAdvertising();
  pAdvertising->start();

  playJingleHappy();
}

void loop() {
  static unsigned long lastTick = 0;
  if(millis() - lastTick > 30000) { // 30 saniyede bir ihtiyac eksilmesi
    lastTick = millis();
    decayNeeds();
  }

  // Buton kontrolleri
  if(digitalRead(PIN_BTN_OK) == LOW) {
    playBeep(1000, 50);
    pet.hunger = min(100, pet.hunger + 25);
    pet.totalScore += 10;
    delay(200);
  }

  renderScreen();
  delay(50);
}

2. Socies İçin Dünyada İlk: 7 Benzersiz (Killer) İnovasyon

🤝
1. ESP-NOW "StreetPass" (Cepte Karşılaşma)
İnternet veya telefona hiç ihtiyaç duymadan! İki Socies kullanıcısı sokakta, otobüste veya okulda yan yana geldiğinde ESP32'ler arka planda birbirini fark eder. Cihaz gizlice cıvıldar ve ekranda "Yeni bir arkadaşla karşılaşıldı: Pamuk (Lv.3 Kedi)!" yazar. Sosyal görevi anında tamamlar!
🏃
2. Gerçek Hayat Alışkanlık Motoru (Habit Sync)
Socies sahibine yük olmaz, sahibini geliştirir! Telefonda "2 litre su içtim", "Kitap okudum" veya "Ders çalıştım" dendiğinde bebeğe süper besin ve ekstra XP gider. Kullanıcının Apple Health / Google Fit adım sayısı bebeğin yürüme ihtiyacını karşılar.
⚔️
3. P2P Bluetooth / ESP-NOW Mini Oyun Düellosu
İki cihazı yan yana getirip Seç butonuna basınca 8-bit refleks yarışı, taş-kağıt-makas veya yemek paylaşma oyunu başlar. Kazanan hayvan ekstra mutluluk ve kozaya geçiş için özel kristal kazanır.
🎨
4. Açık Kaynak Topluluk Pixel-Art Editörü
Kullanıcılar web sitesindeki 16x16 / 32x32 piksel editörüyle kendi hayvanlarını, şapkalarını veya animasyonlarını çizip tek tuşla Bluetooth üzerinden ESP32 flash belleğine yükleyebilir.
🎵
5. 8-Bit Chiptune Beste ve Melodi Paylaşımı
Pasif buzzer sadece bip sesi çıkarmaz; bebek mutlu olduğunda minik Game Boy melodileri çalar. Mobil uygulamadan bebeğe özel melodi bestelenip cihaza zil sesi olarak gönderilebilir.
⚡
6. ULP & Deep Sleep ile 30 Gün Pil Ömrü
Akıllı güç mimarisi: Ekran 45 sn sonra kararır. Dahili RTC 15 dakikada bir uyanıp ihtiyaç durumunu kontrol eder. Acil durum yoksa uykuya geri dalar. Butona basıldığı mikrosaniyede uyanır. 500mAh pil aylarca dayanır.
🏅
7. Koza Sonrası Efsanevi Metamorfoz Sistemi
3 ay boyunca hayvana nasıl bakıldığına göre (daha çok oyun mu oynandı, yemek mi verildi, sosyalleşildi mi?) koza evresinden çıkacak canlı farklılaşır: Sibernetik Kedi, Anka Kuşu, Ejder Balık veya Altın Pacman!

📜 Oyun Kuralları & Sims Dinamikleri

1. Seçilebilir Başlangıç Hayvanları

Açılışta rastgele veya seçimle belirlenen 7 karakterin temel metabolizma farkları:

  • 🐱 Kedi: Yüksek sevgi ve uyku ister. Bağımsızdır, oyun ihtiyacı daha yavaş düşer.
  • 🐶 Köpek: Çok sosyaldir, yüksek oyun ve sevgi bekler. İlgisiz kalırsa hızla üzülür.
  • 🐦 Kuş: Hızlı bir metabolizmaya sahiptir, yemek ihtiyacı diğerlerine göre %50 daha hızlı tükenir.
  • 🐟 Balık: Akvaryum suyu kirlendiği için Temizlik (Hijyen) ihtiyacı en hızlı azalan hayvandır.
  • 🌭 Sosis: Sürekli acıkan, mizahi ve eğlenceli reaksiyonlar veren gurme bir karakter.
  • 🟡 Pacman: Sürekli enerji ve yemek tüketir; arcade tarzı ses efektleri çıkarır.
  • 🦀 Yengeç: İnatçı ve dayanıklıdır; su/kum temizliği ister, özel kıskaç dansı animasyonuna sahiptir.

2. Yaşam Evreleri & 3 Aylık Koza Süreci

  1. Yumurta Evresi (0. Gün): Kullanıcı cihazın butonlarına tıklayarak veya telefondan sallayarak yumurtayı çatlatır.
  2. Bebeklik (1 - 15. Gün): İhtiyaçlar hızlı azalır, ilgi ister. Minik sprite boyutundadır.
  3. Çocukluk (16 - 45. Gün): Oyun oynamayı öğrenir, yeni animasyonlar ve mimikler kazanır.
  4. Yetişkinlik (46 - 90. Gün): Tam boyuta ulaşır, günlük görevlerde maksimum puan getirir.
  5. Koza Evresi (90. Gün): 3 gün boyunca koza içinde uykuya yatar.
  6. Metamorfoz Evrimi (93+. Gün): Bakım geçmişine göre efsanevi üst düzey türe dönüşür!

3. Kritik İhtiyaç Kuralları

⚠️ %50 Altı Kuralı: Herhangi bir ihtiyaç %50'nin altına indiğinde cihaz buzzer ile uyarı verir, OLED ekranda yanıp sönen bir ikaz belirir ve mobil uygulamaya anlık bildirim düşer.
🚫 %0 Kilitlenme Kuralı: Eğer bir ihtiyaç %0 olursa evcil hayvan hastalanır/inatlaşır. O ihtiyaç giderilmeden başka hiçbir aktivite (oyun, sosyalleşme vb.) yapılamaz.
⏳ 5 Gün İhmal Cezası: Tüm ihtiyaçlar %0 seviyesine inip 5 gün boyunca müdahale edilmezse hayvan bir önceki evresine düşer. Eğer zaten 1. evredeyse (Bebek) cezalandırılarak yeniden yumurtaya döner!
